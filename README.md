# Task Management System

A task management system for creating, assigning, tracking, and completing work across projects.

## Structure

- `docs/` - product, API, database, prompt, and implementation notes.
- `backend/` - backend application source.
- `frontend/` - frontend application source.

## Planned Features

- User authentication and profile management.
- Projects, task lists, and task cards.
- Status, priority, due date, and assignee tracking.
- Comments and activity history.
- Search, filtering, and sorting.
- Optional AI-assisted task generation and summarization.
